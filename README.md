# 🛍️ 복주머니 (Talent Pocket)

### 덕성여자대학교 학생을 위한 교내 재능 거래 플랫폼

> 나의 재능을 나누고, 덕우의 재능을 만나다.

**복주머니**는 덕성여자대학교 학생들이 자신의 재능을 등록하고, 필요한 재능을 찾아 거래할 수 있도록 기획한 Android 애플리케이션입니다.

덕성여대 캐릭터 ‘**복단이**’와 ‘**재능을 담은 주머니**’에서 이름을 가져왔으며, 1:1 거래부터 여러 학생이 함께 참여하는 1:N 재능 공유까지 지원합니다.

---

## 📌 프로젝트 배경

학생들은 과외, 디자인, 코딩, 수공예 등 다양한 재능을 가지고 있지만, 이를 교류할 기회는 일반 커뮤니티의 개별 모집 글에 의존하는 경우가 많습니다.

모집 글 탐색부터 판매자의 작업물 확인, 일정 조율, 거래 후 후기 작성까지 하나의 흐름으로 연결하기 위해 **교내 재능 거래에 특화된 플랫폼**을 기획했습니다.

### 기획 방향

- **교내 중심의 연결**: 같은 학교 학생들이 재능을 매개로 교류
- **재능 활용 기회 확대**: 소소한 취미부터 전공 지식까지 등록
- **그룹 기반 재능 공유**: 같은 관심사를 가진 학생들이 함께 참여
- **거래 정보 통합**: 게시글·포트폴리오·리뷰·일정을 한곳에서 확인

학교가 학생 복지 차원에서 운영하는 서비스를 목표로 기획했으며, 실제 학교 공식 운영 서비스와는 구분되는 학생 프로젝트입니다.

## ✨ 주요 기능

### 1. 재능 탐색 및 등록

- 카테고리별 재능 목록 조회
- 키워드 기반 재능 검색
- 재능 상세 정보 및 판매자 프로필 확인
- 재능 등록 시 모집 인원과 모집 기간 설정
- 모집 기간이 종료된 게시글 비활성화

### 2. 1:1 및 1:N 재능 거래

#### 1:1 거래

- 재능 상세 페이지에서 거래 신청
- 신청 후 채팅방으로 연결
- 채팅을 통해 거래 내용과 일정 조율

#### 1:N 그룹 거래

- 판매자가 모집 인원과 거래 가능한 시간대 설정
- 구매자가 원하는 시간대를 선택하여 그룹 참여 신청
- 현재 참여 인원 및 모집 인원 확인
- 참여 인원에 따른 시간대 색상 구분
- 모집 인원 충족 및 예약 확정 시 그룹 채팅방 생성

### 3. 판매자 페이지

판매자의 정보를 확인하고 거래 여부를 판단할 수 있습니다.

| 항목 | 기능 |
| --- | --- |
| 게시글 | 판매자가 등록한 재능 조회 및 거래 신청 |
| 포트폴리오 | 판매자의 작업물과 관련 자료 확인 |
| 리뷰 | 거래 이용자의 별점과 후기 확인 |
| 일정 | 거래 가능한 시간대 확인 및 그룹 참여 신청 |

### 4. 실시간 채팅 및 알림

- 거래 신청 시 채팅방으로 연결
- 1:1 채팅 및 그룹 채팅
- 새로운 채팅 메시지 알림
- 예약 확정 알림
- 거래 예정 시간 30분 전 알림

### 5. 거래 완료 및 리뷰

- 채팅방의 거래 완료 버튼을 통해 리뷰 작성 화면으로 이동
- 5점 만점의 별점 및 후기 작성
- 후기 10자 이상 작성 시 리뷰 등록 버튼 활성화
- 리뷰 등록 후 완료 메시지 전송
- 리뷰 작성 완료 시 거래 완료 버튼 비활성화

### 6. 찜 기능

- 관심 있는 재능을 찜 목록에 저장
- 찜 상태에 따른 아이콘 색상 및 숫자 변경
- 마이페이지에서 찜한 재능 조회
- 찜 취소 기능

### 7. 마이페이지

- 프로필 정보 확인
- 게시글·포트폴리오·리뷰를 탭으로 구분
- 포트폴리오 이미지 등록 및 카드 목록 조회
- 시간표 이미지 등록
- 찜 목록 관리
- 로그아웃

### 8. 로그인 및 생체 인증

- 이메일·비밀번호 기반 로그인
- 자동 로그인
- Android BiometricPrompt API를 활용한 생체 인증
- 기기가 지원하는 지문 또는 얼굴 인증 방식 활용
- 생체 인증을 사용할 수 없는 경우 이메일·비밀번호 로그인 지원

> 생체 정보는 앱에서 직접 수집하거나 저장하지 않으며, Android 시스템의 인증 결과를 활용합니다.
> 지원 가능한 인증 방식은 기기 하드웨어와 설정에 따라 달라집니다.

## 🔄 서비스 이용 흐름

### 판매자

1. 회원가입 및 로그인
2. 재능 내용·모집 인원·모집 기간 등록
3. 포트폴리오 및 일정 등록
4. 거래 신청 또는 그룹 참여 신청 확인
5. 채팅을 통한 세부 사항 조율
6. 재능 제공 및 거래 진행
7. 등록된 리뷰 확인

### 구매자

1. 회원가입 및 로그인
2. 카테고리 또는 검색으로 재능 탐색
3. 판매자의 게시글·포트폴리오·리뷰·일정 확인
4. 1:1 거래 신청 또는 원하는 시간대의 그룹 참여 신청
5. 채팅을 통한 거래 내용 확인
6. 재능 거래 참여
7. 거래 완료 후 별점 및 리뷰 작성

> 거래는 대면 진행 및 현장 결제를 전제로 기획했으며, 앱 내 결제 기능은 제공하지 않습니다.
